## 8. Запрещённые варианты

| Не использовать | Использовать |
|---|---|
| СААС, Саас | SaaS |
| кофаундер (в основном тексте) | соучредитель |
| «делать деньги» | зарабатывать |
| «принять решение о том, чтобы» | решить |
| «на ежедневной основе» | каждый день |
| «является» без нужды | «—» или активный глагол |
| «данный» | «этот» |
| «в рамках» | «в», «при», «во время» |
| «функционал» (о продукте) | «функции», «возможности» |
| «юзабилити» | «удобство использования» |
| «хардкорный» | «сложный», «требовательный» |

## 9. Как добавлять термины

1. Найти термин в исходнике.
2. Проверить, нет ли уже строки в глоссарии.
3. Предложить вариант с учётом контекста.
4. Добавить строку в нужную группу.
5. Поставить статус 🟡, если есть сомнения.
6. В PR описать, почему выбран этот вариант.
7. После утверждения редактором поставить ✅.

**Не** добавляй термин сразу в ✅, если он спорный. Лучше вынести на обсуждение, чем потом менять по всей книге.
