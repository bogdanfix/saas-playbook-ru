# Бриф на перевод

**Книга:** Rob Walling. *The SaaS Playbook: Build a Multimillion Dollar Startup Without Venture Capital*  
**Язык:** русский  
**Объём:** ≈46 000 слов исходника, ≈52 000–55 000 слов перевода  
**Формат:** Markdown по главам → HTML-сайт + EPUB  
**Репозиторий:** публичный GitHub + GitHub Pages

---

## 1. Задача

Сделать качественный русский перевод книги для чтения напарником. Не подстрочник и не «машинный перевод с правками», а нормальный русский текст, в котором:

- сохранён смысл, цифры, примеры и структура оригинала;
- сохранён голос автора — прямой, практичный, с иронией;
- термины употребляются единообразно;
- текст приятно читать с телефона или читалки.

## 2. Что входит в работу

- Перевод основного текста: предисловие, введение, 7 частей, послесловие и приложение.
- Обновление глоссария по ходу работы.
- Самопроверка: сверка цифр, имён, ссылок, заголовков.
- Участие в двуязычной редактуре (или её организация).
- Сборка EPUB/HTML — по договорённости.

**Не входит:** вёрстка печатной книги, дизайн обложки, юридическая экспертиза, публичное продвижение.

## 3. Стиль

- Обращение — **«вы»**, со строчной.
- Буква **«ё»** используется.
- Заголовки — sentence case: «Как выстроить ценообразование?».
- Кавычки — «ёлочки», тире — длинное.
- Компании и продукты — латиницей: HubSpot, Basecamp, TinySeed.
- Имена — транслитерация: Роб Уоллинг, Джейсон Коэн.
- Термины — по глоссарию; первый раз можно дать английский оригинал в скобках.
- Никакого канцелярита, «является», «данный», «в рамках».
- Примеры и реалии не русифицируем: доллары остаются долларами, Огайо — Огайо.

Подробно — в [STYLEGUIDE.md](STYLEGUIDE.md).

## 4. Что сдаётся

По каждой главе:

1. Markdown-файл в `chapters/`.
2. Заполненные метаданные: `title`, `original_title`, `source_pages`, `status`, `translator`, `editor`.
3. Обновлённый `GLOSSARY.md`, если появились новые термины.
4. Pull request с описанием: что сделано, какие места спорные, что осталось на редактуру.

**Критерий готовности главы:**

- все подразделы на месте;
- нет `TODO` и `[[?`;
- цифры, имена и ссылки сверены;
- термины совпадают с глоссарием;
- текст читается вслух;
- `mkdocs build --strict` проходит.

## 5. Процесс

1. **Пилот** — 1 000–1 500 слов: начало введения + раздел о ценообразовании. Цель — согласовать голос и термины.
2. **Черновик** — по главам, в книжном порядке.
3. **Самопроверка** — сверка с исходником, чтение вслух.
4. **Двуязычная редактура** — редактор идёт по оригиналу и переводу параллельно.
5. **Языковая редактура** — стиль и естественность.
6. **Корректура и QA** — орфография, ссылки, сборка.
7. **Релиз** — EPUB и тег версии.

## 6. Сроки

Ориентир для одного человека на полную занятость: **10–13 недель** на весь текст с редактурой.  
Если работа идёт по вечерам: **7–10 месяцев**.  
Пилот: **3–5 дней**.

Точный график — после пилота: он покажет реальную скорость.

## 7. Доступ и инструменты

- Публичный GitHub-репозиторий и сайт на GitHub Pages.
- Доступ к чтению — по ссылке; отдельная учётная запись не нужна.
- Markdown-редактор: VS Code, Obsidian, iA Writer — любой.
- Сборка сайта: `mkdocs serve`.
- EPUB: `pandoc` (если нужен).
- Исходный PDF в репозиторий не коммитится; он хранится отдельно.

## 8. Что нужно от тебя

- Подтвердить стиль: «вы», «ё», полный объём.
- Сказать, какие термины вызывают вопросы.
- Пройти пилот и дать обратную связь по голосу.
- Не выдавать текст за официальное издание и не продавать его: права на оригинал принадлежат автору.
